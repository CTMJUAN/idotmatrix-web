# Matrix Control

A browser-based controller for iDotMatrix BLE pixel displays, built with Web Bluetooth. It doesn't need the official app, an account or an internet connection to the vendor.

**Open it:** the GitHub Pages link for this repo, in Chrome or Edge (desktop or Android) or Bluefy (iPhone).

- `index.html`: the controller (a single file with no dependencies)
- `idm.py`: the same commands as a Python CLI (`pip install bleak pillow`)
- `PROTOCOL.md`: the BLE protocol, reverse-engineered from the official Android app v2.1.6
